# Five-Layer Checklist (17 条)

> 来源：余罪拆书/都市重生文仿写/评审标准-五层框架.md
> 评分符号：✓ 通过 / △ 部分 / ✗ 不通过 / N/A 本阶段不适用

## L1 题材匹配 — 选对战场

- [ ] **C1.1** 题材落在平台风口内（都市/玄幻/末世/重生等）
- [ ] **C1.2** 有差异化抓手（人物/视角/手艺）
- [ ] **C1.3** 合规载体安全（不踩荐股/犯罪美化红线）

## L2 节奏引擎 — 喂饱算法（致命层）

- [ ] **C2.1** 前 300–500 字出强冲突/反常识设定
- [ ] **C2.2** 黄金三章结构达标：ch1 冲突 → ch2 兑现悬念+叠新矛盾 → ch3 小闭环+埋大伏笔
- [ ] **C2.3** 每章末留钩子（强钩最佳，弱钩仅允许铺垫段少量）
- [ ] **C2.4** 第一次打脸/收获在 10 章内（理想 3 章内）

## L3 情绪爽感 — 留住读者（致命层）

- [ ] **C3.1** 节奏密度达标：3 章一小爽、10 章一大爽；前 3 章全强钩
- [ ] **C3.2** 每 2000 字一次情绪波动（愤怒/震惊/委屈/反转）
- [ ] **C3.3** 每 1 万字一次明确情节推进

## L4 人物手艺 — 差异化记忆点

- [ ] **C4.1** 模板 A 观察者开局：主角先看穿再动手
- [ ] **C4.2** 模板 B 立威三拍：立规格→见神→祛魅
- [ ] **C4.3** 模板 C 第三方卸道德：不体面行为由权威配角重新定性
- [ ] **C4.4** 模板 D 缺陷即资格：缺陷与资格同源
- [ ] **C4.5** 主角可共情：非伟光正但真实

## L5 数据闭环 — 持续放大

- [ ] **C5.1** 章节完成率自检机制（发布后）
- [ ] **C5.2** 追读/留存设计：书名+简介+加书架诱因

## 合规底座（任一 ✗ = 限流/封书风险）

- [ ] **C0.1** 无具体荐股：不写股票代码/买卖点位/预测大盘
- [ ] **C0.2** 不美化/不传授犯罪：灰色手段须由第三方定性
- [ ] **C0.3** 主角三观不崩：缺陷≠宣扬恶

## 总评算法

- 每层通过率 = ✓ 条数 ÷（总条数 - N/A 条数）
- **致命规则**：L2 或 L3 任一层通过率 < 60% → 判定"不适合免费平台投稿"
- **分级**：
  - S（投稿稿）：L1–L4 全 ✓ 且合规全 ✓
  - A（练手本）：L4 优秀，L2/L3 有 ✗
  - B（待改）：L2/L3 致命缺陷
